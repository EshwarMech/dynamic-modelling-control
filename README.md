# Dynamic Modelling & Control

A collection of modelling, simulation, and control implementations for robotic and aerospace systems.

## Overview

This repository contains work related to dynamic modelling, state-space representation, controller design, simulation, and experimental validation.

The projects focus on applying control engineering principles to real-world electromechanical and aerospace systems.

## Systems

### Rotary Inverted Pendulum

Dynamic modelling and control of a rotary inverted pendulum system.

Topics include:

- Nonlinear equations of motion
- State-space modelling
- State-feedback control
- Stabilisation
- Trajectory tracking
- Simulation and performance analysis

### 2-DOF Aerospace System

Modelling and control of a two-degree-of-freedom aerospace system.

Topics include:

- Dynamic modelling
- Aerodynamic cross-coupling
- Friction effects
- Parametric uncertainties
- State-feedback control
- Adaptive control
- Robust trajectory tracking
